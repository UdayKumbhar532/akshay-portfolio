# Peddi Akshay - Premium Data Analyst Portfolio

A high-performance, modern personal developer & analytics portfolio built for **Peddi Akshay** (Aspiring Data Analyst & Business Intelligence Analyst), closely replicating the design language, layout, visual hierarchy, and user experience of [chandanprusty.in](https://chandanprusty.in/).

---

## 🚀 Key Features & Highlights

- **Aesthetic Inspiration**: Designed with the typography, sleek card surfaces, subtle borders, and smooth interaction model of Chandan Prusty's portfolio, customized for a modern data analytics profile.
- **Section Order (Exact Specification)**:
  1. **Sticky Navigation Bar** (with active scrollspy, AP logo, theme switcher, and animated mobile drawer).
  2. **Hero Section** (with availability indicator, dual CTAs, value indicators, tech badges, and an interactive simulated analytics dashboard with SVG revenue trend curves and KPI micro-cards).
  3. **About Me** (2-column desktop / 1-column mobile layout, profile card, technical pillars, and structured personal rows).
  4. **Skills & Expertise** (6 modular cards covering Data Analytics, Programming, Databases, Business Intelligence, Reporting, and Professional Skills).
  5. **Featured Projects** (Prominently showcasing the *Food Stall Sales Analytics & Business Reporting* project with 5,000+ records metric, reported 18% inventory forecast improvement, interactive case study modal with SQL snippets, and cohort charts).
  6. **Professional Journey** (Vertical timeline connecting CodeAlpha, CodeSoft, Bite & Buzz, and Singareni Collieries).
  7. **Certifications & Achievements** (Verified credentials from CodeAlpha and CodeSoft).
  8. **Education & Qualifications** (B.Tech CSE from Bhaskar Engineering College, Diploma from Singareni Collieries Polytechnic, and SSC from Montessori High School).
  9. **Dedicated Contact Section** (Direct channels: Email, Phone, Location, LinkedIn, and an interactive message form with client-side validation and feedback states).
  10. **Footer** (AP logo, quick links, tools stack, theme controls, and copyright).
- **Interactive Resume Modal**: Recruiters can preview, print, or save a clean 1-page CV directly from any device.
- **Theme Support**: Flawless Dark Mode and Light Mode with persistent localStorage preference and zero flash on load.
- **Responsive Across All Viewports**: Tested for 320px, 360px, 375px, 390px, 414px, 430px, 768px, 1024px, 1280px, and 1440px+.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS with custom clamp typography and glassmorphism utilities
- **Icons**: Lucide React
- **Typography**: Inter & Plus Jakarta Sans

---

## 💻 Development & Deployment Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle (outputs to /dist)
npm run build

# Preview production build locally
npm run preview
```
